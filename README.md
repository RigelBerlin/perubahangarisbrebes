Aplikasi ini merupakan dashboard interaktif dengan menggunakan package Streamlit yang disediakan oleh Python yang menampilkan hasil deteksi, analisis, dan prediksi garis pantai yang terjadi di Kabupaten Brebes dengan menggunakan data dari citra satelit.

Dashboard ini bertujuan untuk memvisualisasikan:
a. Hasil deteksi garis pantai tahun 1990-2024
b. Analisis perubahan garis pantai tahun 1990-2024
c. Prediksi garis pantai tahun 2034 dan 2044
